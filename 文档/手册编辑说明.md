# 手册内容编辑说明

手册正文在 `手册内容.md` 里编辑,保存后运行 `文档\_build\gen_manual.py` 即可重新生成 `使用手册.pdf`。一般不需要动生成脚本;只有改字号、颜色、页边距、封面文案时才编辑 `_build\gen_manual.py` 顶部的样式区与 `COVER` 字典。

## Markdown 写法速查

| 想要的效果 | 这样写 |
| --- | --- |
| 章标题(居中、进目录) | `# 第1章 认识 PvZWSTools` |
| 小节标题(进目录) | `## 1.1 软件简介` |
| 正文段落 | 直接写文字;同一段不要空行,空行代表分段 |
| 无序列表 | 每行以 `- ` 开头 |
| 有序列表 | 每行以 `1. ` `2. ` 开头(序号自动排) |
| 表格 | 每行以 `|` 分隔,第一行为表头;列宽按内容自动分配,短内容列自动居中 |
| 提示框 | 单独一行 `> 提示:这里是内容` |
| 注意框 | 单独一行 `> 注意:这里是内容` |
| 红字加粗 | `!!重要内容!!` |
| 粗体 | `**粗体内容**` |
| 链接 | `[显示文字](https://网址)` |
| 常见问题 | 问题行以 `问:` 开头,下一行以 `答:` 开头,自动套用问答样式 |

## 注意事项

- 文件开头(第一个 `# 章标题` 之前)的段落,会排在首页"目 录"之前,作为手册前言。
- 标题里的章节编号(`第1章`、`1.1`)是手写的,新增章节请按现有编号顺延;目录和页码会自动重排,无需手工维护。
- 按钮名建议保持『』标注;链接必须是 `[文字](网址)` 成对写法,直接裸贴网址不会生成可点击链接。
- 生成方式(任选其一):
  - **双击 `文档\一键生成手册.cmd`**(推荐,自动找 Python、出错停住显示原因);
  - 或在 ZCode 里直接说"重新生成使用手册"。
- 若生成时 `使用手册.pdf` 正被阅读器打开,脚本会自动把新版存为 `使用手册_新.pdf`,关闭阅读器后改名即可。
