# PvZWSTools 更新说明

本说明对比上一发布版本 **v2026.09.18**，覆盖其后的全部改动。

## Windows 端：界面换了一整套

- 新界面（NewUI）改为顶部连接栏 + 功能搜索框 + 左侧导航 + 底部功能栏：左侧是『收藏』、12 个功能页和『控制台』，一行一个功能，翻页找按钮的日子结束了。
- 顶部搜索框按名称搜全部功能，结果会标出它属于哪一页，收藏星标可以直接在搜索结果里点。
- 『收藏』页新增并改成启动默认页：常用的那几个开关打开软件就在眼前。
- 同类功能收成一块，不再各占一行：『魅惑有效/取消限制』并进『施加僵尸状态』同一行；『同步出怪列表』并进『出怪类型』那一框；40 个出怪勾选整块算一个功能——占一行、一个收藏星、搜一次只命中一条。
- 经典界面保留。底部『UI』窗口里可以切「经典 UI / NewUI」和「黑夜 / 白天」，选择会记住，改动重启后生效。
- 经典界面也补上了夜间模式，并修掉深色下黑底黑字的问题。
- 换肤时弹窗边框、按钮颜色一起跟着主题刷新，不再残留写死的颜色。
- 设置对话框改成常规自适应布局，修掉复选框长文案被裁切，字号提到 16 与主界面一致。
- 一轮走查修复：勾叉垂直居中、字号统一、状态框文字居中、限定植物框对齐、阵型布局还原、组内输入位排布。

## 连接失败：改成照现场给结论

以前不管什么错都弹「确认游戏是否已打开并允许联网权限」，而连本机根本不经过 Windows 防火墙，那句话等于把人往没用的方向支走。这一版改成读现场证据再判断：

- 新增『诊断』页（仅 Windows 端）。『连接诊断』读本机的端口占用表，往『控制台』写五行现场结论：当前地址与错误码、结论、找到的游戏进程、游戏在听的端口、这个端口上都有谁在监听，并按原因给对应的下一步（没人听 / 端口被抢 / 绑址不对 / 回环被截走 / 系统保留段 / 跨机不通）。
- 『端口占用探测』填端口号试着申请一次，用来区分「端口空着但系统不给用」和「端口真的被人占着」。它只在确认没人监听时才去占，不会抢正在用的端口，也只在你点按钮时发生，自动连接不碰它。
- 认出游戏在听的不是 8080（比如 8081）时，工具自动改指过去，不用你手改地址；地址框里只要是你自己改过的内容，工具就不再动它。
- 「去开对端放行入站」这类提示只在连接另一台设备时才出现。连本机不需要放行防火墙。
- 同一个原因在一次断线里只报一次，不再跟着自动重连的节奏刷屏。

## 新增的功能

- **僵尸页 · 小丑辣椒爆炸时间**：在小丑僵尸、辣椒僵尸头上画出离爆炸还剩多久。无头、被冻、被糊、暂停、时停以及『丑椒不爆』开着时，会直接说明现在为什么不炸，而不是甩一个静止的读数。
- **僵尸页 · 忍者僵尸可见**：把隐身中的忍者僵尸画出来给你看。只动绘制，不动植物的瞄准与命中判定——灯笼草照旧看不见它。
- **娱乐页 · 紫卡直接种植**：紫卡无视底座随时可选中，按底座地形直接落土。
- **娱乐页 · 手套常驻 / 垃圾桶常驻 / 融合常驻**：原来这三个是快捷脚本，现在做成了页面上的开关。
- **植物页 · 伞弹车常驻**。
- **出怪页 · 下一波**，以及『同步出怪列表』的新用法：开着它，游戏会在换关、初始化、读档时主动把当前出怪列表推过来，界面上的 40 个勾选始终是游戏里的实际值，不再点一次问一次。
- **阵型页 · 戴夫选卡**，并增加可选数量。
- **杂项页 · TodCheatKeys**：打开游戏内置的 TOD 调试按键——开场动画点一下即跳过，选卡页多出『随机』，挑战页能翻页，窗口失焦时也不再自动弹暂停框。
- **资源页 · 解锁全部商店物品**：把快捷脚本那份的模式 1 做成免参数按钮，点一下就把能永久解锁的项目写进存档（只增不减，金盏花每日限购照原样留着）。改写前先回传一行 Base64 备份，要还原仍在快捷脚本页走模式 3——那行备份界面上选不中，得去『配置文件/Log』最新那份日志里搜 STOREPURCHASES_B64_START 取。
- **战场页 · EasyPlanting 改成开关**：原来点一次是"读当前值取反再弹一个游戏内的提示框"，工具上看不出此刻是开着还是关着；现在和『自由种植』同一形态，状态点在界面上跟着翻，不再弹框。游戏自己的作弊按键（'8' 取反、'q' 一键布阵）仍然会绕过工具直接改这个值，对不上时再点一次开关即可。
- **快捷脚本 · 新建植物**：用游戏未占用的编号往里注入一株新植物，选卡与图鉴会补出格子。
- **快捷脚本 · 解锁全部商店物品**：三种模式，带回滚。
- **杂项页 · 游戏速度**：改速度做成开关加档位选项，页面上直接调，另外补进两个改速度的社区脚本。
- 新增一批 Dev_ 调试脚本：出怪汇流点验证、击杀分类统计、卡槽定价改写、导出阳光花费表、控制台探针、游戏内浮标验证。

## Android 端

- 与 Windows 端改用同一份功能清单，页面顺序和开关名称两端对齐，以后加功能两边一起有。
- 『收藏』页同步可用，长按功能行即可收藏。
- 连接收敛到与 Windows 同一套服务，断线提示同一套规则。
- Beta 包加上与 Windows 同一套准入锁。
- 设置对话框补齐快捷脚本的参数输入界面；『连接』独立成页，抽屉导航分「更多功能」组。

## 双端共同

- 退出先确认再安全退出：点叉、按返回键不再直接关闭；确认框里可以勾「不再弹出提示」，勾上之后跳过确认，但存按钮状态、停自动重连、断开连接的流程照旧走完。
- 界面文案接入多语言：简体中文 + English。Windows 端在『UI』窗口里切，Android 端在设置里切，切换后重启生效。
- 『立即回档』在读档前后清理无效粒子，修掉反复存读档触发的游戏报错。
- 『立即存档』『立即回档』修掉一条必然超时的路径：如果这次点击本来就发生在游戏自己的主线程上（比如从游戏内面板点），当场就做，不再排队等下一帧绘制而白等十秒；从工具点的照旧排队，两边各走各的。
- 启动时清理过期日志，按天保留且至少留够十份。
- Windows 发布包改为「根目录两个入口 exe + app\ 目录」，配置根不再跟着工作目录走。日常双击 PvZWSTools.exe，不带黑窗口；排查时改用 PvZWSTools.Console.exe，多开一个日志窗口，工具本身起不来也能看见卡在哪一步。两个入口是同一个程序，配置与状态通用，正式版也有。
- 下载渠道以夸克为首并常驻入口。
- 分发产物开始携带许可声明：LICENSE、第三方声明表和各项许可正文随包走。
- 使用手册重排：新增第 16 章『诊断页』，状态管理与获取更新顺延为 17、18 章；PDF 改用允许嵌入的开源字体重新输出。第 2 章补了两个入口的分工，第 3 章加了「工具自己打不开」的问答。
