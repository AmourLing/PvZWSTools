PvZWSTools 是一款为 PGvZ、PvZ.net 等植物大战僵尸改版游戏打造的玩家辅助工具,支持 Windows 与 Android 双平台。工具通过连接游戏内建的脚本服务即可使用各项功能,提供出怪控制、战场编辑、阵型管理、快捷脚本等丰富玩法辅助,无需修改任何游戏文件。

使用中遇到问题,欢迎加入官方交流群(!!1034609947!!)提问。提问时建议附上软件截图与游戏完整截图,并说明所用的软件版本、游戏版本与操作步骤,以便更快定位问题。

为便于阅读,本手册约定:按钮、页签等界面元素以『』标注;正文中带底色的“提示”“注意”方框,分别为使用技巧与需要留意的事项。本手册面向普通玩家,不涉及脚本编写等开发内容;如需了解二次开发,请前往 GitHub 仓库查阅相关文档。第4章至第16章按主界面页签顺序,逐章介绍 12 个功能页与花园页。

# 第1章 认识 PvZWSTools

## 1.1 软件简介

PvZWSTools通过 WebSocket 与游戏内建的脚本服务通信:工具界面上每一个按钮、每一个开关,都对应一段发送给游戏执行的指令,由游戏实时完成对应效果。因此工具不需要写入或修改游戏文件,游戏更新后一般也只需更新脚本配置即可继续使用。

软件分为 Windows 版与 Android 版,两端功能基本一致:Windows 版连电脑上的游戏,Android 版连手机上的游戏。两端界面形态与部分按钮名称有所差异,对照详见 1.4。

## 1.2 功能一览

工具主界面共 12 个功能页签,覆盖从基础开关到深度玩法的各个方面:

| 页签 | 主要用途 |
| 杂项 | 游戏速度、清除迷雾、自动收集、取消冷却等常用全局开关 |
| 关卡 | 切换关卡模式、设置无尽旗数、直接过关等关卡控制 |
| 资源 | 修改阳光、金钱及其上限,调整掉落物价值、攻击伤害与植物血量 |
| 植物 | 植物无敌、快速准备、清醒、血量显示等植物强化开关 |
| 僵尸 | 僵尸无敌、停滞、一键魅惑等僵尸行为开关 |
| 出怪 | 控制每波出现哪些僵尸、出怪节奏,自定义波次出怪表 |
| 战场 | 在草坪上任意摆放植物、僵尸、物品与道具,管理小推车与存档 |
| 挑战 | 一键开启砸罐子、我是僵尸、老虎机等挑战玩法 |
| 阵型 | 一键布阵、存储阵型,管理卡组、卡槽与选卡 |
| 娱乐 | 随机罐子、随机卡槽等趣味玩法开关 |
| 快捷脚本 | 运行内置脚本,带说明与参数输入界面 |
| 诊断 | 连不上时读本机端口现场给出原因,并可探测某个端口能否使用(仅 Windows 端) |

## 1.3 使用前的准备

- 游戏端需使用支持脚本服务的改版版本(如 PGvZ、PvZ.net 等),并在游戏内开启对应服务;
- 建议工具与游戏保持版本配套,遇到兼容问题时优先把两侧都更新到最新版;
- Android 端需在系统里允许该应用联网,否则连不上游戏。

## 1.4 两端差异对照

Windows 端与 Android 端的核心功能一致,主要差异如下,使用前请先了解自己所用端的形式:

| 项目 | Windows 端 | Android 端 |
| 界面形态 | 顶部连接栏与功能搜索框 + 左侧导航(收藏、12 个功能页、控制台) + 底部功能栏 | 侧滑抽屉导航,『连接』为独立页面 |
| 功能页面 | 12 个功能页,另有『收藏』『控制台』两页 | 12 个功能页,另有『收藏』『控制台』两页,『连接』独立成页 |
| 功能搜索 | 顶部搜索框按名称搜全部功能,结果标出所属页签;收藏星标直接在结果里点 | 无搜索,靠抽屉分页 |
| 设置类入口 | 底部『状态管理』『环境』『UI』『获取更新』按钮 | 抽屉“更多功能”组:状态管理、设置、获取新版本 |
| 界面风格与主题 | 『UI』窗口里可切 经典 UI / NewUI 与 黑夜 / 白天 | 不提供,固定为适配手机的深色界面 |
| 诊断页 | 有:『连接诊断』给现场结论,『端口占用探测』探端口能否使用 | 无此页;连不上时按提示确认游戏已启动、应用已允许联网 |
| 文件目录 / 界面缩放 | 底部按钮支持 | 无此功能 |
| 波次表编辑 | 应用内编辑框(与手机端同一份实现) | 应用内编辑框 |
| 收藏功能条目 | 任意一行左侧点星标 | 长按功能行 |
| 首次启动 | 安装后即用 | 首次启动需等待解压资源("正在准备资源文件") |

## 2.2 安装与首次启动

!!Windows 端!!:双击安装包,按提示完成安装即可。工具不需要放进游戏目录,可安装在任意位置;阵型、脚本等配置文件保存在程序运行目录旁的『配置文件』文件夹中,可随时通过底部『打开文件目录』按钮打开。程序目录根上有两个入口:PvZWSTools.exe 是日常用的那个,不带黑窗口;PvZWSTools.Console.exe 会多开一个日志窗口,工具本身打不开、点开就闪退时用它才看得到卡在哪一步。两个入口是同一个程序,配置与状态完全通用,开始菜单里带 (Console) 后缀的那条就是后者。

!!Android 端!!:安装 APK 前需允许安装未知来源应用。首次启动会出现『正在准备资源文件』提示,这是在解压内置的脚本与配置资源,等待完成后即可正常使用,请勿强制关闭。

## 2.3 连接游戏

绝大多数功能都需要先连接游戏,步骤如下:

1. 启动游戏并进入存档,确认所用改版已开启脚本服务(一般可在游戏 MOD 菜单中开启);
2. 打开 PvZWSTools。Windows 端顶部地址栏默认为 ws://localhost:8080/Py;Android 端打开抽屉中的『连接』页,在地址框填入地址。两端连的都是自己设备上的游戏,保持默认地址即可;
3. 点击『连接』。连接成功后按钮变为『断开连接』,游戏内会弹出"已成功与PvZWSTools连接"的提示。

> 注意:如果连接失败,Windows 端会先读本机的端口占用表,认出游戏实际在听哪个端口并把地址指过去,不再是从 8080 开始逐个撞;找不到游戏时才退回依次尝试 8080、8081、8082(Android 端始终是依次尝试这三个端口)。仍连不上时请检查游戏是否已经启动、脚本服务是否开启,并到『诊断』页点一次『连接诊断』,它会直接说出现场是哪一种(Windows 端,详见第16章)。可在『环境』(Android 端为『设置』)中勾选『允许自动连接』,工具会自动反复尝试,直到连上为止。地址只要是你自己在框里改过的,工具之后就不再自动改动它。

## 2.4 主界面一览

!!Windows 端!!:顶部是 WebSocket 地址栏与『连接』按钮,右侧一个功能搜索框;左侧导航列出『收藏』、12 个功能页(杂项至诊断)与『控制台』;底部一排常用入口:

- 『获取更新』:检查并安装新版本(详见第18章);
- 『打开文件目录』:打开配置文件所在文件夹,阵型、快捷脚本、选项都在里面;
- 『状态管理』:保存与恢复各页签的开关、输入框状态(详见第17章);
- 『UI』:切换界面风格(经典 UI / NewUI)与主题(黑夜 / 白天),详见第17章;
- 『环境』:打开软件设置(详见第17章);
- 『界面缩放』:点击 + / - 调整界面大小,默认 100%。

顶部搜索框按名称搜全部功能,标题会显示"命中 N 个功能",每条结果右侧标出它属于哪个页签;不想翻页时直接搜更快。

!!Android 端!!:采用侧滑抽屉导航,从屏幕左缘向右滑(或点击左上角菜单图标)打开抽屉。抽屉上半部分是 12 个功能页(杂项至快捷脚本)与『连接』页;"更多功能"分组提供『状态管理』『设置』『获取新版本』,底部同时显示当前版本号。Android 端没有『诊断』页。

两端在功能页之外还有两页:『收藏』与『控制台』。

- 『收藏』是启动默认页,分上下两块。上面的『常用』按点击次数列出你最常用的功能,最多 5 条,收藏过的不再重复出现;下面的『收藏』是你自己钉住的条目,顺序跟着功能清单走。收藏的入口:Windows 端在任意一行左侧点星标,Android 端长按功能行(收藏后的行前面带 ★)。改动当场保存,重启后还在。
- 『控制台』显示日志与 WebSocket 的收发内容,可以在里面直接输入 Python 语句发给游戏,用于临时验证;它不参与开关状态的保存与恢复。

# 第3章 常见问题

本章整理了使用中最常遇到的问题与解决方法;各项功能的完整介绍,将从第4章开始按页签顺序逐一展开,遇到问题时也可随时回到本章查找。

问:点击『连接』提示连接失败?
答:先确认游戏已经启动并进入存档、所用改版开启着脚本服务。端口不用你猜:Windows 端会读本机的端口占用表,认出游戏实际在听哪个端口并直接指过去,只有在找不到游戏时才退回依次尝试 8080、8081、8082(Android 端依次试这三个端口)。还是连不上就到『诊断』页点一次『连接诊断』(Windows 端),它按现场给结论——游戏没开、端口被别的程序占着、端口申请被挡、地址不通,每种对应的下一步见第16章那张表。连本机是不需要放行防火墙的,Windows 防火墙不管设备内部的连接;Android 端则需在系统里允许该应用联网。

问:点按钮提示 WebSocket 未连接?
答:说明尚未连接游戏或连接已断开。先点击顶部『连接』,看到游戏内弹出连接成功提示后再操作。

问:提示"脚本文件不存在"?
答:工具依赖运行目录旁的『配置文件』文件夹。请勿单独移动主程序,建议重新解压完整压缩包;Android 端重装应用即可重新释放资源。

问:界面开关和游戏里的实际效果对不上?
答:在杂项页点『更新按钮状态』同步一次(Windows 端,见第4章);Android 端开启『允许自动更新按钮状态』后,切换页面即会自动同步;也可在『环境』或『设置』中开启该选项(见第17章)。

问:点『波次出怪(数量)』没有出现编辑框?
答:这一步要先从游戏导出当前关卡的波次表,不在关卡内时拿不到数据;进关后再点一次(详见第9章)。

问:打开工具提示"程序已过期"?
答:测试版有效期为发布后 14 天。过期窗口中可点击『检查更新』进入仅更新模式获取新版,或到官方群、网盘下载最新正式版。

问:存储阵型时名称重复会覆盖吗?
答:不会。重名阵型会自动追加 _1 后缀另存;想删除阵型,到『配置文件/阵型』文件夹删除对应 json 文件即可(阵型功能详见第12章)。

问:手机首次启动一直显示"正在准备资源文件"?
答:这是在解压内置脚本资源,视手机性能需要等待片刻,请保持前台等待完成,不要强制关闭。

问:游戏突然闪退怎么办?
答:可先运行快捷脚本『尝试取消异常报错闪退』缓解;若仍复现,请到官方群反馈,并附上操作步骤与相关截图。

问:工具自己打不开,或者点开一闪就没?
答:换带日志的那个入口:双击程序目录里的 PvZWSTools.Console.exe(开始菜单里是带 (Console) 后缀的那条),黑窗口会直接写它停在哪一步——界面没起来时『控制台』页是看不到的,日志同时存在『配置文件/Log』里。也别单独搬动 app\ 里的文件或只复制根上的入口出去,那样它会找不到主程序。

问:想把自己的阵型、出怪配置分享给朋友?
答:把『配置文件/阵型』下的阵型 json、『配置文件/出怪』下的波次 json 发给对方,放进相同位置的文件夹即可直接使用。

问:改好的波次表想下次进关再用,要重新编辑一遍吗?
答:不用。在编辑框点『仅保存』,改动只写进 配置文件/出怪/ZombiesInWave.json;下次进关后点出怪页的『载入已存波次表』即可灌回当前关卡(详见第9章)。

# 第4章 杂项页:常用全局开关

杂项页汇集了最常用的全局开关,点击即开启、再次点击即关闭,效果实时生效。

## 4.1 开关一览

| 开关 | 作用 |
| 清除迷雾 | 去除浓雾关卡的雾,视野一目了然 |
| 罐子透视 | 罐子逐渐变透明,可直接看到里面的内容,砸罐子模式利器 |
| 阳光增值 | 阳光产出价值提高约一倍(小阳光 25、普通 50、大阳光 100) |
| 自动收集 | 阳光、金币、巧克力、礼物盒等掉落物落地即自动收取 |
| 取消冷却 | 卡片种下后立即刷新就绪;关闭开关不会回退进行中的冷却 |
| 自动浇水 | 花园植物自动浇水,还会顺手施肥、喷药、放唱片(消耗对应道具) |
| 取消阳光 | 种植费用恒为 0,任意铺场 |
| 后台运行 | 游戏窗口切到后台时照常运行、不暂停,方便挂机 |
| 去除遮挡 | 移除草丛、电线杆等挡住草坪的场景遮挡物 |
| 补充肥料杀虫剂 | 花园肥料与杀虫剂不足时自动补满 |
| TodCheatKeys | 打开游戏内置的 TOD 调试按键:开场动画点一下即跳过,选卡页出现『随机』按钮,挑战页出现翻页按钮 |

## 4.2 游戏速度与智慧树

『游戏速度』下拉框可在 1/10、1/2、1、2、3、5、10 倍之间切换,选择后立即生效;想恢复正常速度选回 1 即可。配合快捷脚本页中的多个速度脚本,还能获得更多变速档位。

在『设置树的高度』左侧输入框中填入数值,点击按钮即可把智慧树设置为指定高度,直接听取高等级智慧树提示。

## 4.3 同步开关状态

如果手动在游戏或其他途径改变了状态,界面开关可能与游戏内实际效果不一致。Windows 端点击『更新按钮状态』,工具会从游戏读取各开关的真实状态并刷新显示;Android 端没有单独的按钮,在『设置』中开启『允许自动更新按钮状态』后,切换页面时会自动完成同步。

> 提示:建议在『环境』(Android 端为『设置』)中开启『允许自动更新按钮状态』,切换页签时工具会自动同步,免去手动刷新。

# 第5章 关卡页:关卡控制

关卡页用于切换与控制当前关卡,各按钮功能如下:

| 按钮 | 作用 |
| 混乱关卡 | 先在左侧下拉选择目标关卡模式(冒险模式还可填关卡号,如 1-1),点击后切换模式或跳关 |
| 设置无尽旗数 | 设定无尽模式要挑战的旗数,默认 2333 |
| EnterNewLevel | 打开游戏内置的关卡输入对话框,输入关卡号或作弊代码进入;需已处于关卡中 |
| 直接过关 | 清除全场僵尸并淡出关卡,立即进入结算 |

# 第6章 资源页:资源与数值

上半部分四个按钮:『设置阳光』『设置金钱』在输入框填入数值后点击,直接改写当前数值;『设置阳光上限』『设置金钱上限』则设定上限,此后拾取或获得的资源不会超过该值。

## 14.1 运行快捷脚本

快捷脚本页会列出『配置文件/快捷脚本』文件夹中的全部脚本。使用方法:

1. 在列表中点击选中一个脚本,页面会显示它的功能说明与作者;
2. 若脚本带有参数,下方会出现输入框或下拉框,并给出参数说明与默认值;
3. 按说明填写参数后点击『执行』,脚本即发送到游戏中运行,效果实时生效。

> 提示:执行任何脚本前请先连接游戏;脚本的参数配置与脚本同名(如 脚本名.py.config.json),一般无需手动修改。

## 14.2 编写快捷脚本:说明与参数配置

一个快捷脚本由两部分组成:脚本文件(.py)与可选的参数描述文件(.config.json),两者都放在『配置文件/快捷脚本』文件夹中即可被自动列出。本节只介绍参数描述文件的写法,脚本本体(.py)如何编写不在本手册范围内。

**命名对应**:参数描述文件与脚本同名,即在 .py 后追加 .config.json——例如 阵型转化.py 的描述文件为 阵型转化.py.config.json。没有描述文件的脚本同样可以运行,只是页面不显示说明与作者,也没有参数输入。

**占位符**:在脚本中需要使用者填写数值的位置,写上 {0}、{1}、{2} 等占位符。执行时,工具把它们替换成页面上填入或选中的值,再发送给游戏。例如『修改完成冒险次数』脚本的核心一行就是:

```
GlobalStaticVars.gLawnApp.mPlayerInfo.mFinishedAdventure = {0}
```

占位符数量不限,从 0 开始编号,先后顺序无所谓。

**描述文件结构**:config.json 共四个字段,其中 replace 用于定义每个占位符对应的参数:

| 字段 | 作用 |
| name | 脚本名称,一般与脚本文件同名 |
| infoall | 显示在脚本页面上的整体功能说明 |
| author | 作者名 |
| replace | 参数定义:键为占位符(如 "{0}"),值为该参数的配置 |

replace 中每个参数又有三个子字段,决定界面长什么样:

| 子字段 | 作用 |
| info | 参数说明,显示为输入项的标签 |
| value | 填写数组时,界面变为下拉框,数组内容即候选项;省略或写单个值时为文本输入框 |
| default | 默认值;省略时下拉框取数组第一项,输入框为空 |

以 example.py 为例,它的描述文件定义了一个下拉框参数:

```
{
    "name": "example.py",
    "infoall": "这是一个示例Python脚本,展示了如何使用配置文件来设置脚本的参数。",
    "author": "Author Name",
    "replace": {
        "{0}": {
            "info": "这是一个示例参数。",
            "value": [1, 2, 3, 4, 5],
            "default": 3
        }
    }
}
```

> 提示:完整模板可参考快捷脚本文件夹中的 example.py 与 example.py.config.json。配置写好保存后,在快捷脚本页重新选中该脚本即可看到说明与参数界面。

# 第16章 诊断页:连不上时先看现场

这一页(仅 Windows 端)不改变任何游戏内的状态,只回答一件事:为什么没连上。

## 16.1 连接诊断

点『连接诊断』,工具读本机的端口占用表,把结果写进『控制台』,一共五行:当前地址与错误码、结论、找到的游戏进程、游戏在听的端口、这个端口上都有谁在监听。

结论是照着现场推的,常见的几种与对应的下一步:

| 结论 | 意味着什么 | 下一步 |
| 没找到游戏进程,这个端口上也没有监听 | 游戏还没开,或脚本服务没起 | 先启动游戏并进入存档 |
| 游戏在监听 8081,不是 8080 | 端口由游戏自己挑,地址写死了 | 工具会自动改指过去;也可手改地址 |
| 8080 已经被某程序(PID)占着 | 别的程序抢先绑住了这个端口 | 关掉那个程序,或让游戏换一个端口 |
| 游戏绑的是 0.0.0.0,但某程序更具体地绑在 127.0.0.1 | 同一个端口上两个服务,本机连过去落到的是对方 | 工具会改走本机的网卡地址;也可关掉那个程序 |
| 游戏进程在,但没有监听任何端口 | 内置服务没起来,或它的端口申请被挡 | 用下面的端口占用探测确认端口能不能绑 |
| 本机连接被拒(10013) | 端口落在系统保留段,或被安全软件插手 | 换端口;这不是防火墙的问题 |
| 地址不可达 | 填的是别的机器 | 此时才需要看对端的防火墙有没有放行入站 |

> 提示:连本机不需要放行防火墙,Windows 防火墙不管本机内部的连接。只有连接另一台设备时,才轮到"放行入站"这一步。

连接失败时的提示框说的就是上面这些结论;同一个原因在一次断线里只报一次,不会跟着自动连接的节奏反复刷屏。地址框里是你自己改过的内容,工具之后就不再自动改动它。

## 16.2 端口占用探测

填一个端口号点按钮,工具试着申请一次这个端口,用来区分"端口空着但系统不给用"和"端口真的被人占着"。

它只在端口上确实没有人监听时才去申请;已经有监听时只报告是谁占着,不会去抢——抢下一个正在被用的端口,反而会造出一个新的连不上。

> 注意:这是整页唯一会去占用端口一下的动作,只在你点按钮时发生,自动连接不会碰它。

# 第17章 状态管理与软件设置

## 17.1 状态管理

Windows 端点击底部『状态管理』(Android 端在抽屉"更多功能"组中打开『状态管理』),可以把所有页签的开关、输入框、下拉框状态整体保存与恢复:输入名称后点『保存当前』建立自己的配置方案;选中任意条目点『加载』一键恢复;『详细信息』展示该条目与默认状态的差异(标星项为开启的开关);『删除』移除不需要的条目。

列表中的『上次状态』由程序在退出时自动保存且不可删除。配合『环境』中的『自动应用上次配置』,下次启动自动恢复全部状态,并在连上游戏后自动重发已开启的开关,无需逐个再点一遍。

## 17.2 环境设置

Windows 端点击底部『环境』打开,Android 端从抽屉"更多功能"里点『设置』。两端共用的设置项:

| 设置项 | 说明 |
| 允许自动连接 | 连接失败后自动反复重试,直到连上游戏 |
| 取消发送连接提醒 | 连接成功后,游戏内不再弹出连接成功提示(Android 端该项写作『取消连接提醒』) |
| 允许自动更新按钮状态 | 切换页签时自动从游戏同步开关的真实状态 |
| 启动时自动检查更新 | 启动时检查新版本,仅提示不自动下载 |
| 自动应用上次配置 | 启动时自动恢复上次关闭前保存的状态 |

Android 端的设置窗口里还多一项『WebSocket 地址』,等价于 Windows 端顶部的地址栏。改动即时生效,退出时自动保存。

## 17.3 界面缩放与文件目录

本节功能仅 Windows 端提供。底部『界面缩放』的 + / - 按钮以 100% 为基准调整界面大小,适配不同分辨率的屏幕。『打开文件目录』直接打开程序所在文件夹——阵型、快捷脚本、选项、出怪表都在『配置文件』子文件夹中,备份或分享配置只需复制对应文件。

## 17.4 界面风格与主题

仅 Windows 端提供:点击底部『UI』打开选择窗口,里面两组选项。

| 选项 | 取值 | 说明 |
| 风格 | 经典 UI / NewUI | 经典 UI 是逐页排布的老版界面,NewUI 按功能清单自动生成单列界面,带收藏与搜索 |
| 主题 | 黑夜 / 白天 | 仅对 NewUI 生效 |

!!改完要重启!!:点『应用』后程序会自动关闭并重新打开——界面模板与功能清单是启动时一次性拼好的,这样切换才不会留下半新半旧的残留。Android 端不提供这组开关,固定为适配手机的界面。

# 第18章 获取更新

## 18.1 检查更新

在『环境』(Android 端为『设置』)中勾选『启动时自动检查更新』后,每次启动会自动检查新版本(仅提示,不自动下载);也可以随时手动检查:Windows 端点击底部『获取更新』,Android 端打开抽屉中的『获取新版本』。更新窗口会显示当前版本号;发现新版本时,会一并列出新版本号、安装包大小与更新说明。

## 18.2 Windows 端更新

在更新窗口选择下载渠道(多个网盘与代码托管线路,会自动优先可用线路),点击『下载并更新』,底部进度条实时显示百分比、已下载大小与速度。下载完成后工具自动校验、替换并重启,全程无需手动操作。

若自动更新服务不可用,工具会提示前往发布页手动下载,按第2章的渠道重新安装即可,配置文件会保留。

## 18.3 Android 端更新

手机端发现新版本后会弹出对话框,显示当前版本、新版本说明与下载渠道(GitHub 海外线路、Gitee 国内线路),选择渠道下载 APK 后,按普通应用安装流程确认覆盖安装即可。

本手册覆盖了 PvZWSTools 的全部常用功能。工具更新频繁,新功能以程序内说明与群公告为准。祝游玩愉快,玩得开心!
